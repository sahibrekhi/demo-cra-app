# Express Entry CRS Calculator

A public, mobile-friendly Canadian Express Entry Comprehensive Ranking System (CRS) score estimator.

## Status

This project is being built. Verify the score against IRCC's official calculator before relying on it for immigration decisions.

## Official references

- [IRCC CRS criteria](https://www.canada.ca/en/immigration-refugees-citizenship/services/immigrate-canada/express-entry/check-score/crs-criteria.html)
- [IRCC Express Entry changes effective November 3, 2026](https://www.canada.ca/en/immigration-refugees-citizenship/services/immigrate-canada/express-entry/changes.html)
- [IRCC official CRS calculator](https://www.canada.ca/en/immigration-refugees-citizenship/services/immigrate-canada/express-entry/check-score.html)
