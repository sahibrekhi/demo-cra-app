# Express Entry CRS Calculator

A mobile-friendly, single-page Canadian Express Entry Comprehensive Ranking System (CRS) score estimator. It includes a current-rules view and a view for the announced changes effective November 3, 2026.

## Run locally

Open `index.html` in a modern browser. No build tools or dependencies are required.

## Deploy with GitHub Pages

The deployment workflow attempts to enable GitHub Pages automatically before publishing.

A GitHub Actions workflow is included at `.github/workflows/pages.yml`. In repository **Settings → Pages**, select **GitHub Actions** as the build and deployment source if it is not already selected. Then check the **Actions** tab for the deployment result.

Expected site URL: https://sahibrekhi.github.io/demo-cra-app/

## Important accuracy note

This is an independent estimate, not an official IRCC calculator. Some CRS categories and eligibility conditions are simplified, so treat the breakdown as indicative and verify your score with the official IRCC calculator before making immigration decisions.
